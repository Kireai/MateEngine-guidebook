## MateEngine 桌宠使用指南


## 1，在哪里下载

   1)免费版可以使用Steam付费版99%的重要功能。

   
   直接在github里搜索mate-Engine可以先浏览到本体和之外的作品。作者与本体地址为
   https://github.com/shinyflvre/Mate-Engine
   ，有release包直接下载，解压后免安装使用。

   
   2)你是个大好人为富有仁，请去正宗的Steam平台上购买，用约26元（精准3.99美元）请原作者喝一杯超大杯奶茶！！


   
## 2，解压release包后会得到游戏文件夹，进入文件夹双击MateEngineX.exe，即可运行使用。
它会先弹出一个粉紫色的窗口，稍等几秒就能看一个可爱的黑衣女孩出现在你的电脑桌面上。
<img width="766" height="802" alt="image" src="https://github.com/user-attachments/assets/9d5b169c-f60f-4b97-a49e-33a76d296080" />


## 3，鼠标操作
   1）左键按住可拖拽人物，点击人物会触发某些反应。拖拽人物可以将人物放在任务栏上，让她坐下或趴下。拖放到窗口上可以让人物坐在窗口上。
   
   2）滚轮调整角色大小。（3.3.0版本暂时没有旋转人物的功能）
   
   3）右键打开圆盘菜单。
 <img width="424" height="620" alt="image" src="https://github.com/user-attachments/assets/3e250a56-4858-4f8b-8fe4-74ed40c00bbf" />
    
菜单里值得注意的选项一个是最下方的会话，点开它会Loading本地大模型，启动简单的聊天功能。如果你的电脑配置不是太好或者你没有耐心等待，这个会话会表现出一部很卡的样子让人以为这个功能不可以使用。
      <img width="750" height="501" alt="image" src="https://github.com/user-attachments/assets/5c1b59e6-38c3-44aa-8974-7dde8a9c298d" />
    如果你问她今年是几几年，她会回答你是2024年。（本地大模型的局限）

    
   *连衣裙图标代表这个人物模型是可以换装的，如果你加载的模型没有换装设计，这个图标是不会出现的。

   
   *播放器图标打开后是空的，你的任何点击都是徒劳的，因为它没有加载到必须的跳舞文件。如果你是Steam版本，可以优先去创意工坊下载dance文件用以体验。

   
   *调节器图标打开后，是一个可以调整模型形态键的滑块。（但是我没有发现它特别有用的地方）
   <img width="804" height="769" alt="image" src="https://github.com/user-attachments/assets/0a487306-f4a1-448c-9ff1-e2d5856c0411" />
   。

   
   悄悄话：其它几个图标的功能简单，请自行探索，多点趣味。
